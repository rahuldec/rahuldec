## 🧠 How I Approach Development

I started from a non-traditional technical background and learned by building real products around real business problems.

Today, my focus is less on writing code for the sake of coding and more on **engineering useful systems**.

That means thinking about:

- Data integrity and edge cases
- Performance and caching
- Reusable components
- API and external-data reliability
- Automated testing and regression prevention
- Admin and end-user workflows
- Production debugging
- UX and product decisions
- Automation of repetitive operational work

I use AI coding tools heavily as a development multiplier, while continuing to build deeper understanding of the systems underneath the code.
